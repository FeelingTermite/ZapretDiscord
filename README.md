> Этот инструмент могут использовать как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские средства. В результате файл удаляется и отправляется в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, предпочтительно добавить исключение; при отсутствии такой уверенности рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS в параметрах самой ОС — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно

2. Загрузите zip/rar-архив со [страницы последнего релиза](https://github.com/FeelingTermite/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и включите "Разблокировать". Пользователям 7-Zip или PeaZip выполнять этот шаг не требуется

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Откройте подходящий файл
    * Чтобы определить рабочую стратегию, перейдите в **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Для установки стратегии в автозапуск выберите **`service.bat`** → `Install Service` → подходящую стратегию

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск подходит для проверки разных стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты (ALT, FAKE и другие), пока не найдёте подходящий именно вам**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — узнать состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и прочих сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — изменить режим обхода сервисов, перечисленных в `ipset-all.txt`.  
  Этот пункт полезен при проверке ресурса, который без zapret доступен, а с ним не работает.  
  В скобках показывается текущий режим:
    - `none` — ни один IP не проверяется
    - `loaded` — IP сверяется со списком
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить выбранный активный fake на другой из каталога `bin`
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность, если Discord внезапно перестал запускаться
  - **`Run Tests`** — запустить проверку стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe, отвечающий за обход. Его можно увидеть на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/FeelingTermite/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - В появившемся каталоге откройте файл `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что `hosts` действительно сохранился.

#### Работоспособность не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/FeelingTermite/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегия может утратить работоспособность со временем.**
> Обнаружение определённой стратегии способно произойти не сразу: она может работать некоторое время, а затем перестать.
> Здесь собрано много разных стратегий обхода. Если ни одна не подходит, создайте новую на основе одной из них и измените её параметры.
> Описание параметров приведено [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` запустите `Run Diagnostics` и проверьте, нет ли ошибок

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- Поочерёдно проверьте другие стратегии, в том числе **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/FeelingTermite/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- В `service.bat` выберите `Remove Services`
- В `service.bat` запустите `Run Diagnostics`; исправьте найденные ошибки и в конце нажмите Y
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/FeelingTermite/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, нажмите его, затем `Применить` и `ОК`
- Распакуйте архив в новую папку в корне диска, исключив пробелы и специальные символы из пути
- Проверьте разные скрипты `general` и доступность интернет-ресурсов. Если текущая стратегия не работает, закройте программу через значок замочка на панели задач и запустите следующую
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` → `Install Service`

### Не работает игра/приложение с включённым запретом

- Проверьте в `service.bat`, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция доступна здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Перепробуйте остальные стратегии, особенно если раньше всё работало
- См. также [#251](https://github.com/FeelingTermite/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` выполните `Run Diagnostics`, затем очистите кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если браузер также не подключается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/FeelingTermite/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/FeelingTermite/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`
- если этого недостаточно, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить доступ ко множеству сайтов. Не оставляйте его включённым постоянно: определите IP-адреса игры и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/FeelingTermite/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/FeelingTermite/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые требуется исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
